# Study-01 - Handwritten Digit Recognition

MNIST-based handwritten digit recognition project with two versions.

## Project Overview
Users draw digits (0–9) and the AI recognizes them with a confidence score. Built as part of an AI practical course assignment.

## Structure
- `desktop_version/` — standalone Tkinter desktop app
- `web_version/` — Flask web app served in the browser

## Common Rules
- All code and comments written in English
- MNIST dataset (70,000 images, 28×28 pixels, digits 0–9)
- Model: scikit-learn SGDClassifier (compatible with Python 3.14)
