# 상식퀴즈

한국사 · 과학 · 지리 · 문화·예술 4개 카테고리, 80문제로 된 상식퀴즈입니다. 빌드 과정 없이 Vanilla JS로 만들었습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 기록은 브라우저의 localStorage에 저장됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 (시작 · 퀴즈 · 결과 · 리더보드 · 대시보드) |
| `style.css` | 디자인, 다크 모드, 반응형, 애니메이션 |
| `questions.js` | 문제 데이터 80개, 카테고리·난이도 필터 |
| `score.js` | `ScoreManager`, 게임 모드, 문제 구성, 힌트, 결과 분석 |
| `storage.js` | `LocalDataManager`, 리더보드, 통계 |
| `app.js` | 게임 진행 (`initGame` → `loadQuestion` → `handleAnswer` → `showFeedback` → `nextQuestion` → `endGame`)과 화면 제어 |
| `tests/test.js` | 로직 테스트 (`node tests/test.js`) |

## 기능

- **게임 모드**: 전체 도전(카테고리별 10문제씩 40문제), 카테고리 도전(10문제), 스피드 퀴즈(20문제, 문제당 15초)
- **난이도 선택**: 전체 / 쉬움 / 보통 / 어려움 (문제가 모자라면 있는 만큼만 출제)
- **점수**: 정답 10점, 10초 안에 맞히면 +3점, 힌트 없이 맞히면 +2점, 콤보 보너스(3연속 +2, 5연속 +5, 10연속 +10)
- **힌트**: 오답 2개 제거, 게임당 3회
- **일시정지**: 타이머가 멈추고 문제가 가려집니다. 다른 탭으로 이동해도 자동으로 일시정지됩니다.
- **결과 분석**: 총점, 정답률, 평균 응답 시간, 최장 연속 정답, 카테고리별 정답률, 틀린 문제 다시 보기, 클립보드로 결과 공유
- **리더보드**: 전체 도전 / 스피드 / 카테고리별 순위를 오늘 · 최근 7일 · 전체 기간으로 볼 수 있습니다. 플레이어별 최고 기록 기준 상위 10명입니다.
- **대시보드**: 플레이 횟수, 최고 점수, 전체 정답률, 성장 그래프(점수/정답률), 카테고리별 정답률, 최근 게임 목록
- **기타**: 다크 모드, 모바일 화면 대응, 효과음(기본은 꺼짐), 키보드 조작

## 문제 작성 기준 (교차 검증 가이드라인)

문제를 추가하거나 고칠 때는 아래를 확인합니다.

1. **정답이 하나뿐인가?** 다르게 해석될 수 있으면 조건을 적습니다 (예: 면적 기준, 2024년 기준).
2. **최상급 표현에 기준이 있는가?** '가장 큰', '최초의' 같은 표현에는 측정 기준을 적습니다.
3. **시간과 범위가 명확한가?** 바뀔 수 있는 정보는 시점을 적고, 지리적·분류적 범위를 한정합니다.
4. **교차 검증했는가?** 의심스러운 정보는 출처 2곳 이상에서 확인하고, 논란이 있으면 주류 학설을 따르거나 다른 문제로 바꿉니다.
